# Пати

Аналог Jackbox для вечеринки: один экран (ноутбук + телевизор), гости играют с телефонов.
Без сервера: связь через публичный MQTT-брокер по WebSocket. Статика, хостится на GitHub Pages.

Игры:
- **Допиши** (как Quiplash): фраза с пропуском, двое дописывают, остальные голосуют.
- **Враньё** (как Fibbage): настоящий факт про свадьбы в мире, все пишут ложь, потом ищут правду.
- **Нарисуй** (как Drawful): каждый рисует своё задание на телефоне, остальные подписывают и голосуют.

Как вести:
1. На ноутбуке открыть `https://nnenoix.github.io/party/#host`, вывести на телевизор.
2. Гости сканируют QR или вводят код на `nnenoix.github.io/party`.
3. Минимум 3 игрока. Кнопка «Дальше» на экране ведущего пропускает любой этап.
4. Ноутбук не перезагружать во время игры: состояние живёт в его вкладке.

Тест в одном браузере: `?r=КОД&p=Имя` делает каждую вкладку отдельным игроком.
Локально: `python -m http.server 8765 --directory .`
